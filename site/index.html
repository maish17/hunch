Project Respite

Robotic Emergency Salvage & Pickup In Treacherous Environments

Autonomous rovers on the Moon need to keep working for years with minimal human input. Respite continually analyzes their telemetry. When it sees an abnormality, it predicts what fault is coming and when, sends the rover to the repair garage, and deploys another rover to finish the job.

The problem

Lunar robot fleets are expected to work through 30–60 day crewed missions, then run on their own for months between them. If a robot breaks down when no technician is around, it stops, and so does the job it was doing.

Messages to and from Earth are delayed, so the fleet has to handle this itself. The repair garage also has limited space, so robots have to go in for repair in the right order and not on false alarms.

How it works

  1. 1

    Read

    Every rover reports its wheel motors, wheel speeds, battery and temperatures once a second.

  2. 2

    Compare

    Each reading is checked against what is normal for the job the rover is doing right now.

  3. 3

    Predict

    When readings drift, Respite names the likely fault and estimates how long until the part fails.

  4. 4

    Repair

    It writes a work order and sends the rover to the repair garage before it breaks down.

  5. 5

    Replace

    A standby rover takes over the job. Every decision is logged so people can check it later.

Why it's built this way

  1. You can always see why

    Respite uses readable rules and measured trends instead of a black-box AI. Every alert shows the readings that caused it.

  2. Normal depends on the job

    A rover hauling cargo draws more power than an empty one. Readings are compared with what is normal for the current task, so hard work is not mistaken for a fault.

  3. Same symptoms, different causes

    A worn wheel bearing and a wheel clogged with lunar dust both slow the wheel down. Only the bearing makes the wheel hotter than its motor explains, and Respite checks for that difference.

  4. Few false alarms

    Garage space is limited. A reading has to stay abnormal before it raises an alert, so one noisy reading never sends a rover in for repair.

  5. Tested against a hidden answer

    We test on simulated rovers with faults we planted ourselves. The model never sees the answer key, so we can measure exactly how early it warned.
